Grain adaptations: synchronous KV transactions, ordered byte-key packing,
serialized-writer read/add/write instead of FDB atomic ADD and conflict ranges,
and unique membership only. Level-zero members store opaque ID payloads with
implicit count 1; sentinels and upper levels store little-endian span counts.
Promotion uses the reference's independent-random option, with six levels and
four promotion bits per level. This is not an FDB-compatible storage format.

The ranked-set tests include cases derived from RankedSetTest.java at the same
commit, plus byte-prefix, mutation, payload, rollback and snapshot checks.
